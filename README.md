# Prime Number Checker

A simple Python program to check if a number is prime.

## Features

- Takes number from user

- Checking prime number

- Dedicated function to check prime number
- Shows appropriate result to the user
- Handles numbers less than or equal to 1
## Technologies Used

- Python
## How It Works
1. User input a number
2. `prime_check()` function checks the number
3. Numbers less than or equal to 1 handled separately
4. Check number is divisible by another number
5. If number is divisible it is not a prime
6. Else it is a prime. :chatgpt-content-reference{index="0"}
